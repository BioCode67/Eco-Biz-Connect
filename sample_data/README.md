# 예시 데이터셋 — Eco-Biz Connect

소상공인 대시보드의 **경영 데이터 업로드** 기능 시연용 CSV입니다.
각 파일은 업종·재무구조가 달라, 업로드하면 **매출 예측·영업이익·비용구조·이상치·ESG 상생지수·우대 대출 추천이 모두 다르게** 산출됩니다(실데이터 분석).

## 업로드 방법
소상공인 로그인(`merchant@ebc.com` / `Merch123!`) → **경영 데이터 → 파일 업로드** → 아래 CSV 선택.

## ESG 산출 신호 (참고)
- **환경(E)**: 공과금(에너지) 비중이 낮을수록 ↑
- **사회(S)**: 인건비(지역 고용) 비중이 높을수록 ↑
- **지배구조(G)**: 일매출 변동성(표준편차)이 낮을수록 ↑
- 종합 = E×0.40 + S×0.35 + G×0.25 · 등급 A(≥90)/B+(≥80)/B(≥70)/C+(≥60)/C(≥50)/D

## CSV 형식
`날짜, 매출액, 매출건수, 객단가, 카드매출, 현금매출, 지출_재료비, 지출_인건비, 지출_임대료, 지출_공과금`
(필수: `매출액` · 데이터 2행 이상. 직접 만들 때 컬럼명은 유지)
